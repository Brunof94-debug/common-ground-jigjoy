What these records do and don't show

Mozaik starts independent loops for two agents. Each calls a local Qwen3 model through llama.cpp with two decoding slots. Overlap counts use actual Mozaik inference start and completion timestamps; they do not measure a speedup or guarantee the model's reasoning is correct. Code checks catalog IDs, integer-cent costs, capacity, access, shelter and a 10% reserve. Agent explanations are generated notes, not verified facts. You make the final decision.
